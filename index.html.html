Emasakulasi Bunga Induk Betina

Proses pemotongan atau pembuangan benang sari (stamen) pada kuncup bunga betina sebelum masak. Hal ini dilakukan untuk mencegah terjadinya penyerbukan sendiri (*self-pollination*).

Poin Biologi Penting:

Bunga Duku tergolong hermaprodit, sehingga emasakulasi wajib dilakukan di pagi hari saat benang sari belum pecah.

Panduan Guru: Integrasi Google Sheets MTsN 6 Tulungagung

Ikuti 5 langkah mudah ini untuk mengaitkan simulator ini dengan Google Spreadsheet milik Guru:

  1. Buka Google Drive > Buat Google Spreadsheet baru.
  2. Buka menu Ekstensi > Apps Script.
  3. Hapus kode lama, lalu Salin & Tempelkan skrip di bawah ini:
function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = JSON.parse(e.postData.contents);
  
  if (sheet.getLastRow() === 0) {
    sheet.appendRow(["Waktu", "Nama Siswa", "Kelas", "Sekolah", "P1", "P2", "Rasio F1", "Unggul %", "Nilai", "Badge"]);
  }
  
  sheet.appendRow([
    data.waktu, data.nama, data.kelas, "MTsN 6 Tulungagung",
    data.p1, data.p2, data.rasio, data.persenUnggul, data.nilai, data.badge
  ]);
  
  return ContentService.createTextOutput("OK").setMimeType(ContentService.MimeType.TEXT);
}
  1. Klik Deploy > New Deployment (Terapkan Baru).
  2. Pilih Jenis: Web App, Akses: Anyone (Siapa Saja). Klik Deploy lalu salin URL yang diberikan ke dalam form simulator!
